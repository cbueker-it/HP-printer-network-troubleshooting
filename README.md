HP-printer-network-troubleshooting

Documented troubleshooting, wireless reconfiguration, network validation, and packet capture analysis for an HP LaserJet M29w printer using TShark.

After relocating to a new residence, an HP LaserJet M29w printer required reconnection to the wireless network. This project documents the troubleshooting process used to restore printer connectivity, verify network communication, and validate successful operation through packet capture analysis.

Evironment:
Ubuntu Linux Desktop
HP LaserJet M29w
Spectrum Router
Google Chrome
TShark

Problem
The printer was no longer connected to the wireless network after moving to a new location. As a result, printing services and web management access were unavailable.

Objectives
Restore printer connectivity
Verify wireless network configuration
Confirm device visibility on the network
Validate communication using packet analysis
Document the troubleshooting process

Skills Demonstrated
Network Troubleshooting
Printer Configuration
DHCP Validation
Embedded Web Interface Administration
Packet Capture Analysis
TShark
